Como levantar el proyecto:
1 - pnpm install
2 - pnpm start

Crear una branch antes de comenzar una tarea:
1 - git checkout -b nombredelarama

una vez que haya terminado con la tarea
1 - git add . 
2 - git commit -m "mensaje resumiendo lo hecho en el commit"
3 - git push
